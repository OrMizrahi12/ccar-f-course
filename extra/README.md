# Extra section student kit: full exam simulation

Claude Certified Architect – Foundations (CCAR-F) · Extra section: full exam simulation

Sixty original questions, run like the real exam: 2:00 on the clock for each question (120 minutes for 60 items),
then the answer, and why every other option is wrong. Like the exam, every question sits inside a scenario. The section
has five videos: how it works, then four parts, one scenario each: Scenario 1 (Customer Support Resolution Agent, questions 1–15), Scenario 4 (Developer Productivity with Claude, questions 16–30), Scenario 5 (Claude Code for Continuous Integration, questions 31–45), Scenario 6 (Structured Data Extraction, questions 46–60).

## What's in the kit

| File | What it is |
|---|---|
| `answer-sheet.pdf` | **Print this first:** the answer sheet, numbered 1 to 60, four parts, with the type of every question |
| `answer-sheet.md` | The same answer sheet, as text |
| `domain-tracker.md` | Your score per domain, with the question numbers of each domain and the lessons to review |
| `answer-key.md` | Every scenario and question with its answer, its domain, task statement and lesson, and the reason for every option. Use it after the videos |
| `lesson-notes.md` | The section's notes: how each question runs, scoring, the chapters of every video, sources and credits |

## How to use it

1. Print or open the answer sheet. No notes and no AI assistant while the clock runs.
2. In each video, read the scenario, then write your answer before every reveal. Pause the video if you need more time, and notice how often.
3. At the end of each part, count your score for that part.
4. After part 4, fill in the domain tracker, and review any domain under 70%: its lessons, then their quick checks.

Scoring rule of this simulation: a multiple-choice question counts when you picked the right letter; a multiple-response question counts only when you picked every correct option and nothing else. The exam reports a scaled score from 100 to 1,000 (720 passes); a raw count here does not convert to it.
