Lesson 5.2: The CLAUDE.md hierarchy. Every command, prompt and key in the lesson, in order (macOS and Linux).
Windows: see README.md for the user-file path, mkdir, the teammate's folder (C:\teammate) and "&&" in Windows PowerShell 5.1.
Run everything from your harborline folder, with .venv active (the prompt starts with (.venv)), unless a line says otherwise.
The kit's harborline/ files are the files typed in the lesson. No API calls: Claude Code runs on your Claude sign-in.

1. The rules nobody else gets
   cd ~/projects/harborline
   git status --short                       (nothing: the tree is clean)
   code ~/.claude/CLAUDE.md                 a new, empty file: your user file
     (Ctrl+J hides the terminal panel)
     type:
       # My notes for Claude

       - Run the tests with: .venv/bin/python -m pytest -q
       - Money: take refund amounts from policy.check_refund, never compute them by hand.
       - Dates: read orders through harborline.normalize, never parse the raw date fields.
       - Commit messages: one line that says what changed.
       - Keep answers short.
     Ctrl+S
   (Ctrl+` back to the terminal)
   clear
   claude -p "Without reading any files: quote the rules you were given for working in this repository, or say there are none. Nothing else."
                                            quoted from your global notes (~/.claude/CLAUDE.md): the five lines

2. A project CLAUDE.md with imports
   clear

   mkdir -p docs/conventions
   code docs/conventions/money.md           type the kit's money.md, Ctrl+S
   code docs/conventions/dates.md           type the kit's dates.md, Ctrl+S
