Lesson 3.2: The support agent: tools, loop and a target. Every command typed in the lesson, in order (macOS and Linux).
Windows: in cmd.exe use "cls" instead of "clear", and run the command after it on its own line (see README.md).
Run everything from your harborline folder, with .venv active (the prompt starts with (.venv)).
Your ANTHROPIC_API_KEY must be in .env (Lessons 0.4 and 0.6). The lesson's runs cost about $0.016 in all.

1. Four tools: two that read, two that act
   cd ~/projects/harborline
   git status --short                       prints nothing: a clean tree after Lesson 3.1
   code support/tools.py                    line 15: from loop.tools import ESCALATE_TO_HUMAN, PROCESS_REFUND
                                            from the old server line to the end: process_refund,
                                            escalate_to_human, TOOLS, server, NAMES; save

2. One ticket, and what the run tells us
   code support/agent.py                    type the file (or copy it from the kit), save
   clear; python -m support.agent T-003
                                            tools: get_customer, lookup_order, process_refund;
                                            a $74.00 refund; success: 4 turns, about $0.0008, session ...

3. The number: first-contact resolution on labeled tickets
   code support/evaluate.py                 type the file (or copy it from the kit), save
   clear; python -m support.evaluate 2> runs/evaluate.log
                                            one line per dev ticket (20), then:
                                            FCR 15/20 (75%) · escalation recall 3/3 · wrong refunds 1 · $0.0146

   clear; git status --short                 M support/tools.py, ?? support/agent.py, ?? support/evaluate.py
   git add support
   git commit -m "Lesson 3.2: the support agent with four tools, and an FCR baseline"
   git push                                 to origin, your own harborline
