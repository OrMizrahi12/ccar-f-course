Lesson 2.7: Built-in tools: Read, Write, Edit, Bash, Grep, Glob. Every command and prompt typed in the lesson, in order (macOS and Linux).
Windows: in cmd.exe use "cls" instead of "clear", and run the command after it on its own line (see README.md).
Run everything from your harborline folder, with .venv active (the prompt starts with (.venv)).
The kit's legacy/warehouse/records.py is the file after the lesson's one Edit: compare it with yours.
No API calls: Claude Code runs on your Claude sign-in.

1. The default tool set
   cd ~/projects/harborline
   clear; claude

                                            codes.py -> compat.py (getStatus = status_name) -> __init__.py -> the test
     Ctrl+O                                 the detailed transcript; Ctrl+O again hides it
     /exit
