Lesson 3.7: Long conversations without losing facts. Every command typed in the lesson, in order (macOS and Linux).
Windows: in cmd.exe use "cls" instead of "clear", and run the command after it on its own line (see README.md).
Run everything from your harborline folder, with .venv active (the prompt starts with (.venv)).
Your ANTHROPIC_API_KEY must be in .env (Lessons 0.4 and 0.6). Each check makes 8 agent calls and 6 summary calls (a few cents).

1. Measure
   cd ~/projects/harborline
   git status --short                       prints nothing: a clean tree after Lesson 3.6
   code support/long_check.py               type the file without the three step-3 lines, save
   clear; python -m support.long_check 2> runs/long_check.log
                                            facts kept 0/9 in the lesson (yours may differ)

2. Case facts and the trim
   code support/case_facts.py               type the file (or copy it from the kit), save
   clear; python -m support.case_facts HL-10187
                                            full 12 fields 484 characters / trimmed 8 fields 292 characters

3. Wire it in
   code support/hooks.py                    after "from harborline import normalize": from support import case_facts
                                            normalize_order docstring: """Give Claude one format, and only the fields that matter."""
                                            clean = case_facts.trim(normalize.order(record))
                                            PostToolUse: a second HookMatcher(matcher="mcp__harborline__.*",
                                                         hooks=[case_facts.record]) (see README.md), save
   code support/long_check.py               from support import case_facts, gates
                                            after gates.start_case(): case_facts.start_case()
                                            prompt = (case_facts.block() + "\n\n"
                                                      f"## The conversation so far (summary)\n{summary or '-'}"
                                            save

4. Measure again
   clear; python -m support.long_check 2> runs/long_check.log
                                            facts kept 9/9

5. Commit
   clear; git status --short                 M hooks.py, ?? case_facts.py, ?? long_check.py
   git add support
   git commit -m "Lesson 3.7: case facts outside the summary, and trimmed order lookups"
   git push                                 to origin, your own harborline
