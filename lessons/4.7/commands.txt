Lesson 4.7: Provenance and conflicting sources. Every command typed in the lesson, in order (macOS and Linux).
Windows: in cmd.exe use "cls" instead of "clear", and run the command after it on its own line (see README.md).
Run everything from your harborline folder, with .venv active (the prompt starts with (.venv)).
Your ANTHROPIC_API_KEY must be in .env (Lessons 0.4 and 0.6). The run in step 4 costs under four cents; the tests call no model.

1. Render and check
   cd ~/projects/harborline
   git status --short                       prints nothing: a clean tree after Lesson 4.6
   code research/provenance.py              type the file (or copy it from the kit), save

2. The report's shape
   code research/agents.py                  change it in place (see README.md, step 2), save
   code research/coordinator.py             change it in place (see README.md, step 2), save

3. Provenance, tested
   code tests/test_provenance.py            type the file (or copy it from the kit), save
   clear; python -m pytest -q tests/test_provenance.py
                                            4 passed
   python -m pytest -q                      104 passed

4. One run
   clear; python -m research.coordinator "Should Harborline charge customers a fee for return shipping?" 2> runs/research.log
                                            timestamped subagent lines (->, <-, verify_fact ...), then the report:
                                            ## Answer, ## Established, ## Contested (Figure | Source | Method tables),
                                            ## Not covered; provenance: ok; subagents: ...; ...s in all · ... turns · $...

5. Commit
   clear; git status --short                M research/agents.py, M research/coordinator.py,
                                            ?? research/provenance.py, ?? tests/test_provenance.py
   git add research tests
   git commit -m "Lesson 4.7: a report that keeps every claim with its source, and shows conflicting figures side by side"
   git push                                 to origin, your own harborline
