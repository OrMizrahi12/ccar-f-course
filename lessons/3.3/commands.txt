Lesson 3.3: Enforcement, not instructions. Every command typed in the lesson, in order (macOS and Linux).
Windows: in cmd.exe use "cls" instead of "clear", and run the command after it on its own line (see README.md).
Run everything from your harborline folder, with .venv active (the prompt starts with (.venv)).
Your ANTHROPIC_API_KEY must be in .env (Lessons 0.4 and 0.6). The gate check makes 10 short agent runs (well under a cent).

1. The gate
   cd ~/projects/harborline
   git status --short                       prints nothing: a clean tree after Lesson 3.2
   code support/gates.py                    type the file (or copy it from the kit), save

2. Wire it in
   code support/tools.py                    line 16: from support import gates
                                            lines 34, 41, 47: reply(backend.X  ->  reply(gates.X
                                            (get_customer, lookup_order, process_refund); save
   code support/agent.py                    line 16: from support import gates
                                            line 41: async def handle(ticket_id, prompt=None):
                                            lines 43-44: gates.start_case(), then
                                            prompt = prompt or first_message(ticket_id)["content"]; save

3. Prove it
   code support/gate_check.py               type the file (or copy it from the kit), save
   clear; python -m support.gate_check 2> runs/gate_check.log
                                            prompt rule only: served 1 on each ticket in the lesson
                                            gate on: served 0, blocked 1 on each ticket

4. Commit
   clear; git status --short                 M support/agent.py, M support/tools.py, ?? support/gate_check.py, ?? support/gates.py
   git add support
   git commit -m "Lesson 3.3: a verification gate for the order tools"
   git push                                 to origin, your own harborline
