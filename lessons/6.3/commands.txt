# Run from your harborline folder in the VS Code terminal, at the Lesson 6.2 commit, with (.venv) active.

# --- Before you start (once, off camera in the lesson): a teammate's branch to review ---
# The lesson reviews a branch called refund-totals with one new file, scripts/refund_totals.py (it's in this kit).
git switch -c refund-totals
cp <kit>/harborline/scripts/refund_totals.py scripts/refund_totals.py
git add scripts/refund_totals.py
git commit -m "Refund totals per customer for the weekly report"
git push -u origin refund-totals
git switch main

# --- The teammate's branch ---
git status --short
set -a; source .env; set +a
git fetch -q && git log --oneline main..origin/refund-totals
git --no-pager diff main...origin/refund-totals

# --- Step 1: criteria in a file ---
clear
mkdir -p ci/prompts
code ci/prompts/review.md
# Type the vague version (review-v1.md in this kit), then save (Ctrl+S).
code ci/review_config.json
# Type {"disabled_categories": []} on three lines, then save.
code ci/review.py
# Make the edits (ci/review.py in this kit is the result): CRITERIA and CONFIG load at the top; the prompt starts with
# CRITERIA; review() drops disabled categories; main() reads result["findings"]; a --local mode; the docstring line. Save.

# --- Step 2: measure the vague version (run it twice) ---
clear
python ci/review.py --local main...origin/refund-totals
clear
python ci/review.py --local main...origin/refund-totals

# --- Step 3: switch off a noisy category ---
code ci/review_config.json
# Change it to {"disabled_categories": ["style"]}, then save.

python ci/review.py --local main...origin/refund-totals
