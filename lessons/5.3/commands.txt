Lesson 5.3: Rules and path-scoped conventions. Every command, prompt and key in the lesson, in order (macOS and Linux).
Windows: see README.md for mkdir and the backslash paths in PowerShell (the globs inside the rule files keep forward slashes).
Run everything from your harborline folder, with .venv active (the prompt starts with (.venv)), unless a line says otherwise.
The kit's harborline/.claude/rules/ files are the files typed in the lesson. No API calls: Claude Code runs on your Claude sign-in.

1. Two scoped rules
   cd ~/projects/harborline
   git status --short                       (nothing: the tree is clean)
   mkdir -p .claude/rules
   code .claude/rules/testing.md            a new, empty file
     (Ctrl+J hides the terminal panel)
     type:
       ---
       paths:
         - "tests/**/*.py"
       ---

       # Tests

       - Name each test for the behavior it checks.
       - Build small order dicts inside the test. Never edit data/*.json for a test.
       - Run the one test file first, then the whole suite.
     Ctrl+S
   (Ctrl+` back to the terminal)
   code .claude/rules/tools.md              a new, empty file
     (Ctrl+J)
     type:
       ---
       paths:
         - "loop/tools.py"
         - "mcp_server/**"
         - "support/tools.py"
       ---

       # Tool definitions

       - A description says what the tool returns, and when to use it instead of a similar tool.
       - Errors go through harborline/tool_errors.py: errorCategory, isRetryable and a message.
     Ctrl+S
   (Ctrl+`)
   clear
