Lesson 4.4: Choosing a decomposition strategy. Every command typed in the lesson, in order (macOS and Linux).
Windows: in cmd.exe use "cls" instead of "clear", and run the command after it on its own line (see README.md).
Run everything from your harborline folder, with .venv active (the prompt starts with (.venv)).
Your ANTHROPIC_API_KEY must be in .env (Lessons 0.4 and 0.6). The two runs together cost under one cent.

1. Two modes in one file
   cd ~/projects/harborline
   git status --short                       prints nothing: a clean tree after Lesson 4.3
   mkdir -p experiments/m4
   code experiments/m4/decompose.py         type the file (or copy it from the kit), save

2. The chain
   clear; python -m experiments.m4.decompose chain 2> runs/decompose.log
                                            five per-file notes (--- legacy/warehouse/<file>), then
                                            --- across the files; 6 calls, fixed before the run · $...

3. The open-ended plan
   clear; python -m experiments.m4.decompose explore 2> runs/decompose.log
                                            numbered tool calls with one-line notes, what changed the plan,
                                            the plan (at most eight lines); N tool calls, chosen during the run

4. Commit
   clear; git status --short                ?? experiments/m4/
   git add experiments
   git commit -m "Lesson 4.4: a fixed review chain, file by file and then across files, and an open-ended plan that adapts"
   git push                                 to origin, your own harborline
