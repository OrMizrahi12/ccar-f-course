Lesson 3.4: Hooks: intercept and normalize. Every command typed in the lesson, in order (macOS and Linux).
Windows: in cmd.exe use "cls" instead of "clear", and run the command after it on its own line (see README.md).
Run everything from your harborline folder, with .venv active (the prompt starts with (.venv)).
Your ANTHROPIC_API_KEY must be in .env (Lessons 0.4 and 0.6). The hook check makes 3 short agent runs (well under a cent).

1. Normalize
   cd ~/projects/harborline
   git status --short                       prints nothing: a clean tree after Lesson 3.3
   code harborline/normalize.py             type the file (or copy it from the kit), save

2. The hooks
   code support/hooks.py                    type the file (or copy it from the kit), save
   code support/agent.py                    line 17: from support.hooks import HOOKS
                                            line 39 (in OPTIONS, after max_budget_usd): hooks=HOOKS,
                                            save

3. Prove it
   code support/hook_check.py               type the file (or copy it from the kit), save
   clear; python -m support.hook_check 2> runs/hook_check.log
                                            called directly: status 7 -> returned; refund $649.00: deny
                                            through the agent: kettle hooks off / on, desk hooks on

4. Commit
   clear; git status --short                 M support/agent.py, ?? harborline/normalize.py, ?? support/hook_check.py, ?? support/hooks.py
   git add harborline support
   git commit -m "Lesson 3.4: a refund-limit hook and normalized orders"
   git push                                 to origin, your own harborline
