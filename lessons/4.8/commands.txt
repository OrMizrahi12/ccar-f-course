Lesson 4.8: State, crash recovery and context budgets. Every command typed in the lesson, in order (macOS and Linux).
Windows: in cmd.exe use "cls" instead of "clear", and run the command after it on its own line; CRASH_AFTER and
$(ls research/runs) are written differently there (see README.md, "Windows, macOS and Linux").
Run everything from your harborline folder, with .venv active (the prompt starts with (.venv)).
Your ANTHROPIC_API_KEY must be in .env (Lessons 0.4 and 0.6). The crashed run in step 4 costs about one cent and
the resume in step 5 just under three cents; the tests in step 3 call no model.

1. State on disk
   cd ~/projects/harborline
   git status --short                       prints nothing: a clean tree after Lesson 4.7
   code research/state.py                   type the file (or copy it from the kit), save

2. Save, resume, crash
   code research/agents.py                  the analyst's prompt: relevance (0 to 1), no reasoning; save
   code research/coordinator.py             save each report, --resume, CRASH_AFTER, the relevance filter; save

3. State, tested
   code tests/test_state.py                 type the file (or copy it from the kit), save
   clear; python -m pytest -q tests/test_state.py
                                            3 passed
   python -m pytest -q                      the whole suite: 107 passed in the lesson

4. A crash
   clear; CRASH_AFTER=3 python -m research.coordinator "Should Harborline charge customers a fee for return shipping?" 2> runs/research.log
                                            run <run_id>, the searchers, the analysts; after the third
                                            saved report: simulated crash
   ls research/runs/*/                      manifest.json and one JSON file per saved report
   clear; cat research/runs/*/manifest.json the question, the saved reports in order, found

5. Resume
   clear; python -m research.coordinator --resume $(ls research/runs) 2> runs/research.log
                                            resuming <run_id>: 3 reports already saved; new subagents
                                            only; the report; provenance: ok

6. Commit
   clear; git status --short                M research/agents.py, research/coordinator.py,
                                            ?? research/state.py, tests/test_state.py
   git add research tests
   git commit -m "Lesson 4.8: each report saved to a run manifest as it arrives, and a crashed run resumed from it"
   git push                                 to origin, your own harborline
