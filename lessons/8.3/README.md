# Student kit: Lesson 8.3, Scenario sprint 2

Claude Certified Architect – Foundations (CCAR-F) · Section 8: Exam Readiness · Lesson 8.3

This lesson adds no code. It recalls the rules behind Scenarios 2, 4 and 5 using earlier lessons' runs. By the end of it you can:

1. Recall the rules behind Scenarios 2, 4 and 5
2. Spot the traps that sound right
3. Apply them to a stem from any of the three

## Where the runs come from

Every run in the lesson was recorded in an earlier lesson. To repeat one, use that lesson's kit:

- **Lesson 5.2** (rule 1): `/memory` lists the user and project instructions and the files they import.
- **Lesson 5.3** (rule 2): path rules in `.claude/rules` load only when a matching file is read.
- **Lesson 5.4** (rule 3): a forked skill finds the tool description that never says what it returns.
- **Lesson 5.5** (rule 4): plan mode, the approval, then the edits and 118 tests passed.
- **Lesson 5.6** (rule 5): tests first, 5 failed; then 6 of 6 and the full suite green.
- **Lesson 5.7** (rule 6): a findings file, `/compact` with a focus, and the notes read back.
- **Lesson 5.8** (rule 7): the MCP tool `trace_export` picked over Grep, and a re-export found.
- **Lesson 6.1** (rule 8): `claude -p` with a JSON schema, and `--bare` skipping CLAUDE.md.
- **Lesson 6.3** (rule 9): what to report, what to skip, and severity defined by example.
- **Lesson 6.4** (rule 10): four findings without examples, the same two findings with them.
- **Lesson 6.5** (rule 11): a cross-file bug, confirmed at 0.97.

Each result comes from one run on the day it was recorded, so yours will differ. This lesson made no API calls and cost nothing.
