Lesson 4.5: Distributing tools across agents. Every command typed in the lesson, in order (macOS and Linux).
Windows: in cmd.exe use "cls" instead of "clear", and run the command after it on its own line (see README.md).
Run everything from your harborline folder, with .venv active (the prompt starts with (.venv)).
Your ANTHROPIC_API_KEY must be in .env (Lessons 0.4 and 0.6). The run in step 4 costs about two and a half cents;
the tests in step 3 call no model.

1. Constrained and scoped tools
   cd ~/projects/harborline
   git status --short                       prints nothing: a clean tree after Lesson 4.4
   code research/tools.py                   change it in place (see README.md, step 1), save

2. Each role its tools
   code research/agents.py                  the analyst gets load_document, the synthesizer verify_fact; save
   code research/coordinator.py             RESEARCH_TOOLS and one sentence of the system prompt; save

3. The limits, tested
   code tests/test_research_tools.py        type the file (or copy it from the kit), save
   clear; python -m pytest -q tests/test_research_tools.py
                                            4 passed
   python -m pytest -q                      the whole suite: 98 passed in the lesson

4. One run
   clear; python -m research.coordinator "Should Harborline charge customers a fee for return shipping?" 2> runs/research.log
                                            searchers call search_web, the analyst load_document,
                                            the synthesizer verify_fact; the answer;
                                            subagents: searcher 1, searcher 2, analyst 1, synthesizer 1

5. Commit
   clear; git status --short                 M research/agents.py, research/coordinator.py, research/tools.py,
                                            ?? tests/test_research_tools.py
   git add research tests
   git commit -m "Lesson 4.5: each subagent gets only its role's tools: load_document for the analyst, verify_fact for the synthesizer"
   git push                                 to origin, your own harborline
